# Python Simple Calculator

## About the Project
This is a beginner-friendly calculator built using Python. It performs basic arithmetic operations based on user input.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero error handling
- Invalid operator handling

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python calculator.py
```

On Windows, you can also use:

```bash
py calculator.py
```

## Example Output
